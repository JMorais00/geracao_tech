# Atividade de Git e GitHub - Geração Tech 4.0

Repositório criado para praticar os comandos básicos de controle de versão utilizando o Git e hospedagem de código no GitHub.

## 🛠️ Tecnologias Utilizadas
* **Git** (Controle de versão local)
* **GitHub** (Repositório remoto)
* **Prompt de Comando (CMD)** do Windows

## 📋 Comandos Praticados
Durante esta atividade, foram utilizados os seguintes comandos principais:
* `git clone <url>`: Para clonar o repositório remoto para a máquina local.
* `git add <arquivo>`: Para adicionar as alterações à área de stage.
* `git commit -m "mensagem"`: Para registrar o commit com uma mensagem descritiva.
* `git push origin main`: Para enviar as alterações locais para o GitHub.
